# Scaffold a service

A file will be created named `service.yaml`. A second one will be written to
`build/manifest.json`, and the run log lands in `logs/scaffold.txt`.

Read `package.json` to find the package name, and `tsconfig.json` for the
compiler settings. Neither ships with this bundle.

Work through `./checklist.md` before you start, and hold the result to
[the naming conventions](context/naming.md).

The template itself is not part of this bundle:

```bash
cat templates/service.yaml
```
